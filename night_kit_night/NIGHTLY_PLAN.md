## 블록 1 — M406 판별 (00:00–04:00) ← 가장 중요

### 1-1. 계측만 추가 (코드, 30분)

`SIM_DIAG_M406=1` 일 때만 켜지는 로그 3줄. **동작은 안 바뀐다.**

| 로그 | 언제 | 무엇 |
| --- | --- | --- |
| `[DIAG] root_writes_after_job=N` | 작업 종료 시 | **작업 시작 이후** 루트(XForm) 자세를 쓴 횟수 — 복귀 보정 루프 포함 |
| `[DIAG] attach_offset_hand=[dx,dy,dz]` | `attach()` 직후 1 스텝 뒤 | (PhysX 실제 책 자세 − 앵커 기준 자세)를 손 기준으로. 실제 자세는 **물리 뷰**(`RigidPrim` 월드 자세)에서 읽을 것 |
| `[DIAG] return_residual=[pos_m, yaw_deg]` | 복귀 보정 종료 시 | **팔 베이스**(`panda_link0`)의 출발 대비 잔차. 루트가 아니다 |

그리고 **0 m 주행** 옵션: `--patrol-zero` — 순회 코드 경로를 그대로 타되 모든 웨이포인트를 출발점으로.

**확인**: 단위시험 통과 + 계측을 켜고 `--no-patrol` 1판이 블록 0 과 같은 결과.

### 1-2. 대조 실험 (15판, 약 90분)

| 조건 | 판수 |
| --- | --- |
| `--no-patrol` | 5 |
| 순회 (지금) | 5 |
| `--patrol-zero` | 5 |

전부 `SIM_DIAG_M406=1`, 세션마다 재시작, book_0.

### 1-3. 재현 실험 (3판, 20분)

주행 없이, 파지 **직전에 책을 물리 API 로 +2 cm (y) 옮겨** 놓고 파지. (USD 쓰기 금지 — 그게 가설의 원인이다)

### 1-4. 결정 규칙 — 결과에 따라 **하나만** 고친다

| 관측 | 판정 | 할 일 (환경변수 뒤에) |
| --- | --- | --- |
| 순회 판에서 `root_writes_after_job > 0` | **H-a** (보정 루프가 작업 중에도 돈다) | `SIM_RETURN_GATE=1`: 보정은 **작업 시작 전에 끝내고**, 끝나지 않으면 작업을 411 로 거절. 순회 5판 재시험 |
| `attach_offset` 크기 ≈ M406 (판마다 ±5 mm 로 같이 움직임) **그리고** 1-3 에서 M406 ≈ 2 cm | **H-b** (앵커가 기대 자세 기준) | `SIM_ATTACH_PHYSICS=1`: 세우기를 **물리 API** 로 → **1 스텝** → 앵커를 **물리 뷰에서 읽은 두 바디 자세**로. 순회 5판 + `--no-patrol` 5판(회귀) |
| `--patrol-zero` 에서도 M406 | 거리 무관 → 코드 경로 | H-a 부터 확인 |
| 어느 것도 아님 | 미확정 | **고치지 않는다.** 표만 남긴다 |

둘 다 해당하면 **H-a 먼저** 고치고 재시험한 뒤 H-b.

**수정 채택 조건**: 수정 뒤 순회 5판 중 4판 이상 M406 < 10 mm **그리고** `--no-patrol` 회귀가 블록 0 보다 나빠지지 않을 것. 못 미치면 **환경변수를 꺼 둔 채** 기록만.

## 블록 2 — 오차 예산 측정 (04:00–05:00, 진실값은 채점자로만)

### 2-1. 지그 오차 — 칸마다 계통인가 무작위인가

책 스폰만 하고 파지하지 않는 세션 **5개**. 칸 0~5 각각:

```
설정 칸 중심 (x, y)  vs  실제 책 AABB 중심 (진실값)
```

| 출력 | 뜻 |
| --- | --- |
| 칸별 평균 오차 | **계통** — 설정을 고치면 된다 |
| 칸별 표준편차 | **무작위** — 설정으로 못 고친다 (멈춤벽이 필요한 근거) |

### 2-2. 비전 오차 통계

같은 세션에서 비전 파지 좌표를 칸마다 **10프레임** — 진실값 대비 x·y 평균·표준편차. **읽기만.** 비전 코드는 건드리지 않는다.

### 2-3. 손가락 여유 실측 — 회신의 "±5 mm" 확인

열린 상태에서 두 손가락 AABB 를 읽어 책 중심 기준으로:

```
손가락 안쪽면 ↔ 집을 책 옆면   (회신 계산: 5.05 mm)
손가락 바깥면 ↔ 옆 책 옆면     (v24: 8.3 mm)
```

작은 쪽이 파지 단계의 진짜 허용치다. 둘 다 적는다.
