## 4. 통합 중 병행 개발

### 1차 통합

이현민이 FSM과 공통 인터페이스를 기준점으로 관리한다. 통합에 참여하지 않는 시간에는 윤재민이 빈 공간 탐지 안정화, 이동준이 재정렬, 김도윤이 파지·삽입 복구를 선행 개발한다. 공통 action 변경은 통합 시간 외에 임의로 반영하지 않는다.

### 2차 통합

9월 24일에는 이현민·윤재민·이동준이 데이터·비전·이동을 연결하고 김도윤은 로봇팔 추가개발과 문서를 맡는다. 9월 25일에는 이현민·김도윤이 예외 삽입을 연결하고 윤재민·이동준은 시험과 문서 검증을 수행한다.

### 3차 통합

신규 알고리즘보다 관제 명령, 실제 FSM 상태와 DB 데이터의 일치 여부를 확인한다. 각 담당자는 자신의 기능 상태가 화면에 정확히 표시되는지 검증한다.

## 6. 일정 운영 규칙

- 휴가·면접 등 가용 시간은 즉시 공유하고 같은 기능의 보조 담당자를 지정한다.
- 매일 종료 전 완료, 미완료, blocker와 다음 날 목표를 기록한다.
- 1차에 영향을 주는 인터페이스는 9월 18일 오후부터 변경을 최소화한다.
- 2·3차 기능이 정상 플로우를 불안정하게 만들면 기능을 비활성화하고 마지막 성공 버전으로 시연한다.
- 9월 27일 18시 이후에는 신규 기능을 추가하지 않고 P0/P1 결함만 수정한다.
