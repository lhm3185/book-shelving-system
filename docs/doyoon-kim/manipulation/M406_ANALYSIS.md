## 1. 증상

```
error_code 406  '운반 중 손 안에서 책 4.7cm 어긋남'   (2026-09-20, M0609 먼 배치)
error_code 406  '운반 중 손 안에서 책 3.1cm 어긋남'   (2026-09-20, Franka 재측정)
```

판정: `carry_rotate` 또는 `wedge` 단계에서
`|book_in_hand(book) − rel0| > 0.03` (`manipulation_executor.py:202`)

---

## 2. 여기서부터가 중요 — **고정 조인트는 이미 걸려 있다**

책을 마찰로 잡는 게 아니라 **손과 책을 고정 조인트로 묶는다** (`book_scene.attach`).
순서를 따라가 보면:

| 순서 | 무엇 | 어디 |
| --- | --- | --- |
| 1 | `grip` — 그리퍼를 **책 두께보다 좁게** 닫는다 | `plan_job` 의 `SetGripper(T/2 − min(0.004, 0.15·T))` |
| 2 | `attach` — 책 자세를 세우고 **고정 조인트 생성** | `book_scene.py:688` |
| 3 | `lift` 시작 — **여기서 `rel0` 을 측정** | `manipulation_executor.py:188` |
| 4 | `carry_rotate` / `wedge` — 여기서 어긋남 판정 | `manipulation_executor.py:202` |

**`rel0` 은 고정 조인트가 생긴 뒤에 잡힌다.** 즉 "조인트가 늦게 걸려서" 가 아니다.
조인트가 걸린 상태에서 4.7 cm 가 밀린다.

---

## 3. 가장 그럴듯한 원인 — 손가락과 조인트가 **서로 싸운다**

두 힘이 같은 책에 동시에 걸린다.

- **고정 조인트**: 책을 손 기준 고정 위치에 붙들려 한다.
  `excludeFromArticulation = True` 라 아티큘레이션 밖의 **최대좌표 조인트**로 풀린다 —
  솔버 반복 횟수가 제한돼 있어 큰 외력이 있으면 밀린다.
- **손가락 접촉**: 그리퍼를 책 두께의 절반보다 **일부러 좁게** 닫아 두었다.
  붙잡을 때는 필요했지만, 조인트가 생긴 뒤에는 **쥐는 힘이 더는 필요 없고**
  접촉력만 조인트에 계속 얹힌다.

여기에 `carry_rotate` 의 손목 회전 각가속도가 더해지면, 접촉력이 조인트를 이기는
구간이 생긴다. **4.7 cm 는 마찰 미끄러짐이라기엔 크고, 튕겨나간 값에 가깝다.**

### 곁가지 의심 — `attach` 안의 자세 교정

```python
if book in self.upright_q:
    p_now = SingleXFormPrim(book).get_world_pose()[0]
    SingleXFormPrim(book).set_world_pose(p_now, self.upright_q[book])
```

**이미 손가락이 닫힌 상태에서 책을 회전시킨다.** 위치는 그대로지만 자세가 바뀌므로
손가락과 겹칠 수 있고, PhysX 가 그 겹침을 밀어내면서 초기 속도가 생긴다.
게다가 순간이동이라 **속도를 0 으로 만들지 않는다.**

## 4. 실험 (Isaac 필요, 각 10분)

순서대로 하나씩. **한 번에 하나만 바꾼다.**

| # | 무엇을 바꾸나 | 이 가설이 맞으면 |
| --- | --- | --- |
| 1 | `attach` 에서 자세 교정을 **건너뛴다** (임시로 `if False:`) | 어긋남이 줄면 → 자세 교정이 원인 |
| 2 | `attach` 직후 책의 선속도·각속도를 **0 으로** 설정 | 줄면 → 순간이동 잔류 속도가 원인 |
| 3 | `attach` 뒤 그리퍼를 **살짝 벌린다**(접촉만 유지) | 줄면 → 손가락·조인트 충돌이 원인 (**본 가설**) |
| 4 | `carry_rotate` 속도를 절반으로 (`speed` 인자) | 줄면 → 각가속도가 원인. 다만 시연 시간이 늘어난다 |

**먼저 측정할 것**: 지금은 `> 0.03` 을 넘을 때만 로그가 남는다.
`carry_rotate` 내내 `dev` 를 남기게 하면 **언제 튀는지**(회전 시작인지 끝인지)가 보인다.
그것만으로 3번과 4번이 갈린다.
