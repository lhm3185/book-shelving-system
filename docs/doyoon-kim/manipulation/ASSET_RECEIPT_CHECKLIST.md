늦게 온 에셋으로 밤을 새워 시도하는 것이 **가장 나쁜 선택**이다. 9/21 아침에 검증 안 된 상태로 시연하게 된다.

| 에셋 도착 | 판단 |
| --- | --- |
| 9/20 13:30 ~ 15:00 | 아래 순서대로 진행. 게이트 2까지 친다 |
| 9/20 15:00 ~ 16:00 | **1~4번을 30분 안에** 끝내고 게이트 1·2 에 집중 |

**9/20 17:00 까지 사용자에게 한 줄로 보고한다** — "9/21 시연은 [새 로봇 / 분리] 로 합니다."

## 1~4. 빠른 확인 (합계 30분)

### 1. prim 경로 (10분)

```bash
cd ~/book-shelving-system
ISAAC_ENTRY=simulation/isaac/tools/probe_carter_deck.py ./scripts/run_isaac_tool.sh --usd <에셋>.usd
```

`simulation/isaac/config/robot_profiles.py` 의 `M0609` 항목과 대조한다.

| 프로파일 항목 | 현재 값 (우리 결합체 기준) |
| --- | --- |
| `root` | `/World/carter_m0609` |
| `base_link` | `arm/m0609/base_link` |
| `hand_link` | `arm/m0609/link_6` |
| `camera_prim` | `arm/onrobot_rg2ft/angle_bracket/realsense_d455/RSD455/Camera_OmniVision_OV9782_Color` |

→ 다르면 **프로파일만 고친다.** 코드는 건드릴 필요 없다.

### 2. 재생 후 안정 (5분) — 이게 제일 중요하다

```bash
ISAAC_ENTRY=simulation/isaac/tools/settle_test_carter.py ./scripts/run_isaac_tool.sh --usd <에셋>.usd
```

| 통과 기준 | 값 |
| --- | --- |
| 기울기 | **1° 미만** |
| 팔–베이스 어긋남 | **5 mm 미만** |

참고: 우리 최종본은 0.15° / 1.4 mm. 고치기 전에는 **91.8° / 235 mm** 였다.

**실패하면 담당자에게 반려한다.** 원인은 십중팔구 둘 중 하나다 (`ASSET_HANDOFF_REQUEST.md` 에 상세):
- 고정 조인트 `localPos0` 을 AABB 중심 기준으로 잡음 → 39 cm 어긋남
- `joint_3`·`joint_5` 드라이브 목표가 90°, 시작 자세는 0°

우리가 고쳐도 되지만 **에셋을 계속 다시 받아야 하므로 담당자 쪽에서 고치는 게 빠르다.**

### 3. 카메라 (5분)

```bash
ISAAC_ENTRY=/tmp/probe_cam_offset.py ./scripts/run_isaac_tool.sh --usd <에셋>.usd
```

| 기대값 | |
| --- | --- |
| 카메라 ← `link_6` | **[+0.0115, +0.0450, +0.0525] m, X축 180°** |

**다르면 즉시 비전 담당에게 새 오프셋을 알린다.** 늦으면 담당자가 남은 시간을 못 쓴다.
(카메라가 팔 쪽 `angle_bracket` 에 붙어 있어 같은 `m0609_gripper.usd` 를 쓰면 그대로일 것이다)

### 4. 그리퍼 (10분)

```bash
ISAAC_ENTRY=/tmp/probe_rg2.py ./scripts/run_isaac_tool.sh --usd <에셋>.usd
```

| 기대 | |
| --- | --- |
| 명령이 먹는 관절 | `left_inner_knuckle_joint` / `right_inner_knuckle_joint` (0.25~0.30 rad) |
| **`finger_joint`** | **거의 안 움직인다 (0.0008 rad) — 명령 대상이 아니다** |

다르면 `robot_profiles.py` 의 `grip_joints` · `grip_open` 을 고친다.

> 파지할 때 **고정 조인트로 책을 붙이므로** 그리퍼가 물리적으로 쥘 필요는 없다.
> 열고 닫는 모습만 나면 된다. 여기서 오래 붙잡지 말 것.
