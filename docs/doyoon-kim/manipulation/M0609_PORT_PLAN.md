## 2. RG2 구동 관절 확인 (코드 수정 전)

그리퍼 관절이 6개로 보이지만 **전부 독립 구동이 아니다.** 평행 링크라 실제 명령 대상은 1~2개이고 나머지는 종속이다.
URDF 임포트에서 종속 관계가 유지되지 않으면 6개가 모두 독립처럼 보인다.

```
확인: 6개 중 명령을 받는 관절은 무엇인가 / 나머지가 따라오는가
방법: 파지를 시도하기 전에 **그리퍼만 열고 닫아** 본다
```

잘못 잡으면 손가락이 비대칭으로 벌어지는데, 증상은 "파지 실패" 로만 보여 원인 추적이 오래 걸린다.
