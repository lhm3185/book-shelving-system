## 4. 시연 중에 알고 있어야 할 함정

| 함정 | 내용 |
| --- | --- |
| **서가 콜라이더** | 16개 중 `shelf_brown__book_shelf_01` **하나만** 물리적으로 존재한다. 다른 서가 앞에서 꽂으면 책이 통과해 바닥으로 떨어진다 |
| **비전 좌표 프레임** | `origin/vision` 이 `target_frame` 을 `base_link` 로 바꿨다. 우리 노드는 `arm_base_link` 아니면 **410 으로 거절**한다. 결합체에서 `base_link` 는 AMR 몸체라 **0.655 m 어긋난다** — 시연 전 담당자와 맞출 것 |
| **비전 CV 창** | `show_debug_window` 기본값이 `false` 로 바뀌었다. 화면을 띄우려면 `-p show_debug_window:=true` |
| **트레이 5·6번 칸** | 신뢰도가 낮다 (기존 실측). 시연은 **0~3번 칸**으로 |
| **한 세션 6권** | 트레이 책은 한 Isaac 세션에 6권이다. 더 하려면 재시작 |
| **도메인** | 작업용 42 가 아니라 **130** |

## 5. 정리 (시연 후)

```bash
# GPU PC — 반드시 PID 를 확인하고 우리 것만 끈다 (팀원 프로세스 금지)
ps -eo pid,etime,cmd | grep "[r]un_simulation.py"
kill <PID>

# 이 PC
pkill -f run_demo_pc.sh ; pkill -f manipulation_node ; pkill -f vision_manager
pkill -f static_transform_publisher
```

> `pkill -f run_simulation.py` 를 ssh 한 줄로 실행하면 **명령 자신이 패턴에 걸려 세션이 죽는다.**
> 반드시 PID 로 끄거나 `P="run_simu""lation.py"; pkill -f "$P"` 처럼 문자열을 쪼갠다.
