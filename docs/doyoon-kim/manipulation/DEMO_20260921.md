## 등장하는 PC 와 터미널

| 이름 | 무엇 | 어디서 여는가 |
| --- | --- | --- |
| **작업 PC** | 내 노트북. ROS 노드와 명령은 **전부 여기서** 친다 | 내 자리 |
| **GPU PC** | Isaac Sim 전용 (`10.10.0.2`). **직접 앉지 않고 작업 PC 에서 ssh 로** 쓴다 | 터미널 A 안 |

터미널은 **작업 PC 에서 4개**를 연다. GPU PC 앞에 가서 칠 것은 없다.

| 터미널 | 역할 | 계속 떠 있나 |
| --- | --- | --- |
| **A** | ssh → GPU PC 에서 Isaac 실행 | **계속 떠 있어야 함** (닫으면 Isaac 종료) |
| **B** | 비전 + 로봇팔 노드 (`run_demo_pc.sh`) | **계속 떠 있어야 함** |
| **C** | 명령 보내기 (`ros2 action send_goal`) | 필요할 때만 |
| **D** | 로그 보기 (선택) | 선택 |

> **`ROS_DOMAIN_ID` 는 터미널마다 다시 설정한다.** 한 터미널에서 `export` 해도
> **다른 터미널로도, ssh 너머로도 안 따라간다.** 9/20 작업은 42 였고 **시연은 130** 이다.

for f in ~/ws_cobot_pjt/arm/models/book_tray_best.pt ~/ws_cobot_pjt/arm/models/shelf_best.pt; do

## 1. 터미널 A — GPU PC 에서 Isaac 실행

작업 PC 에서 새 터미널을 열고:

```bash
ssh rokey@10.10.0.2
```

프롬프트가 `rokey@IsaacSim16:~$` 로 바뀐 뒤, **GPU PC 안에서** 아래를 통째로 붙여넣는다.

```bash
cd ~/b1_arm
BOOKS=$(ls ~/book_dataset/usd_v2/book_encyclopedia_set_01_2k__book_encyclopedia_set_01_book0[1-6].usdc | paste -sd,)
echo "책 $(echo $BOOKS | tr , '\n' | wc -l)권"      # 6 이어야 한다

ARM_ROBOT=m0609 \
ROS_DOMAIN_ID=130 \
FASTRTPS_DEFAULT_PROFILES_FILE=$HOME/.ros/fastdds_whitelist.xml \
SIM_USD=$HOME/Desktop/Collected_ing_library_env_v5-firstFinal/level_yaw0.usd \
./scripts/run_isaac_sim.sh \
  --start-home snap \
  --camera-prim /World/Nova_Carter_ROS/m0609/onrobot_rg2ft/angle_bracket/realsense_d455/RSD455/Camera_OmniVision_OV9782_Color \
  --sensor-policy always \
  --book-variants "$BOOKS"
```

**약 4분** 걸린다. 아래 두 줄이 나오면 준비 완료:

```
### 시작 자세를 홈으로 고정 (오차 0.0012 rad)
### 준비 완료 (step 3) — 명령 대기 /manipulation/sim/command
```

**이 터미널은 그대로 둔다.** 닫으면 Isaac 이 죽는다.

| 증상 | 원인 / 조치 |
| --- | --- |
| `쓸 수 있는 책 원본이 없다` | `--book-variants` 가 비었다. `echo $BOOKS` 로 6개인지 확인 |
| `invalid choice: 'set'` | `--start-home` 값은 `snap` 또는 `move`. `set` 아님 |
| `준비 완료` 대신 `시작 홈 이동 실패` | `--start-home snap` 을 빠뜨렸다. Ctrl+C 후 다시 |
| 4분 넘게 아무 변화 없음 | 다른 Isaac 이 이미 떠 있는지 0번 3) 확인 |

## 3. 터미널 C — 명령 보내기 (작업 PC)

**이 터미널에서 먼저** 환경을 잡는다 (터미널마다 매번 해야 한다).

```bash
source /opt/ros/jazzy/setup.bash
source ~/ws_cobot_pjt/book-shelving-system/ros2_ws/install/setup.bash
export ROS_DOMAIN_ID=130
export FASTRTPS_DEFAULT_PROFILES_FILE=$HOME/.ros/fastdds_whitelist.xml
```

연결 확인 — 여기서 안 보이면 **다음으로 넘어가지 말 것**:

```bash
ros2 action list | grep place_book
```

파지 명령:

```bash
ros2 action send_goal /place_book shelving_interfaces/action/PlaceBook \
"{job_id: 'demo1', book_id: 'book_0', target_slot: {header: {frame_id: 'arm_base_link'}, pose: {position: {x: -0.3497, y: 0.5495, z: 0.3399}, orientation: {z: 0.7071068, w: 0.7071068}}, confidence: 1.0}}"
```

**이 배치에서는 접근·파지까지 간다.** 운반 단계에서 M406(손 안에서 책이 미끄러짐)이 날 수 있다 —
기존 이슈이고, 시연에서는 **"집어 드는 것까지"** 를 보여준다.

| 증상 | 원인 / 조치 |
| --- | --- |
| `ros2: command not found` | 위 `source` 두 줄을 안 했다 |
| `place_book` 이 안 보임 | ① 터미널 B 가 떠 있는지 ② A·B·C 모두 `130` 인지 |
| `410 ... frame_id` | `frame_id` 는 반드시 `arm_base_link` |
| `411 트레이 칸 N 에 책 없음` | 그 칸 책을 이미 썼다. `book_id` 를 바꾸거나 Isaac 재시작 |

## 5. 시연 구성 — (가)를 시도하고, 안 되면 (나)

| 안 | 내용 | 상태 |
| --- | --- | --- |
| **(가)** | M0609 결합체가 트레이 책을 집어 **서가에 꽂는다** | **미완** — 서가 앞 배치에서 `approach` 가 어깨 막힘으로 실패 |
| **(나)** | ① M0609 결합체가 트레이 책을 **집어 든다** + ② Nova Carter **주행** | ①은 9/20 확인됨 (위 1~3번이 그것) |

### 아침 1시간 상자 — 순서를 **지금** 정해 둔다

| 단계 | 내용 | 시간 |
| --- | --- | --- |
| **0** | **확정 시험** — `SIM_TRAY_COLLIDER=0` 으로 띄워 같은 동작을 돌린다 | 5분 |
| 1 | 트레이가 원인으로 확정되면 → **아침 배치의 트레이↔팔 베이스 상대 좌표를 복원** | 15분 |
| 2 | `check_reach` 로 4칸 IK 재확인 | 5분 |
| 3 | 접근 1권 → 파지 1권 | 20분 |

0번은 §6 의 서가 앞 구성에 **환경변수 하나만** 더해서 띄운다:

```bash
SIM_TRAY_COLLIDER=0    # 진단 전용. 시연에는 절대 쓰지 말 것 (책이 트레이를 통과한다)
```

접근 자세에 **도달하면 → 트레이가 원인, 확정.** 여전히 못 가면 → 트레이가 아니다 → IK 가지 유도로.
(파지는 어차피 실패한다. 보는 것은 `approach` 가 끝나는지 하나뿐이다)

**0번을 건너뛰면 안 된다.** 고쳐져도 왜 고쳐졌는지 모르게 된다.

**팔 높이를 바꾸는 안은 하지 않는다.** 팔 기준 z 가 전부 무효가 되어
삽입 z 0.5097 · x 대역 4/4 · 받침판–서가 여유 4.8 cm 를 전부 다시 재야 한다.

> **1시간 안에 접근이 안 끝나면 (나)로 간다.** 이건 약속이다.

## 7. 시연 중에 알고 있어야 할 함정

| 함정 | 내용 |
| --- | --- |
| **터미널마다 도메인** | `export` 는 터미널을 넘지 않고 ssh 도 넘지 않는다. A·B·C 각각 `130` |
| **서가 콜라이더** | 16개 중 `shelf_brown__book_shelf_01` **하나만** 물리적으로 존재한다. 다른 서가 앞에서 꽂으면 책이 통과해 바닥으로 떨어진다 |
| **비전 좌표 프레임** | `origin/vision` 이 `target_frame` 을 `base_link` 로 바꿨다. 우리 노드는 `arm_base_link` 아니면 **410 으로 거절**한다. 결합체에서 `base_link` 는 AMR 몸체라 **0.655 m 어긋난다** (9/20 슬랙으로 되돌림 요청함) |
| **비전 CV 창** | `show_debug_window` 기본값이 `false` 로 바뀌었다 → §2 의 `VISION_EXTRA` 로 켠다 |
| **트레이 5·6번 칸** | 신뢰도가 낮다. 시연은 **0~3번 칸**으로 |
| **한 세션 6권** | 트레이 책은 한 Isaac 세션에 6권. 더 하려면 재시작 |
| **Isaac 재시작 = 노드 재기동** | 터미널 A 를 다시 띄웠으면 **터미널 B 도 반드시** 다시 |

## 8. 발표에서 "안 된 것" 을 말하는 방식

기준은 하나다 — **심사자가 결과를 오해하게 되는가.**
오해하게 되면 숨기면 안 되고(2/4 를 4/4 로, 분리를 통합처럼),
오해할 일 없으면 굳이 안 보여도 된다(실패한 시도 20번, 중간 버그).
**정직의 대상은 결과이고, 생략해도 되는 것은 과정이다.**

"안 됐다" 에는 셋을 반드시 붙인다:

| | 없으면 |
| --- | --- |
| ① 어디까지 됐는지 — **측정값으로** | "못 했다" 로만 들린다 |
| ② 왜 안 됐는지 — **추측이 아니라 배제 결과로** | 변명으로 들린다 |
| ③ 무엇을 하면 되는지 — **다음 단계로** | 끝난 것처럼 들린다 |

②는 이미 있다 — `docs/doyoon-kim/web_claude/v20.md` §5 의 **배제 표**(7개 의심 중 6개를 실측으로
지우고 1개를 남긴 표)를 슬라이드에 그대로 올린다.

### 발표 순서 (나)

| # | 무엇 | 형식 | 말할 것 |
| --- | --- | --- | --- |
| 1 | Franka 파지·삽입 | 녹화 | **2/4 로 정정해서** |
| 2 | M0609 파지 (먼 배치) | 라이브 또는 녹화 | 접근·파지까지 |
| 3 | Nova Carter 주행 | 라이브 | |
| 4 | 통합이 왜 남았는가 | 슬라이드 1장 | 배제 표 + 다음 단계 |

> **라이브는 오늘 재현된 것만 한다.** 오늘 안 된 것을 당일 라이브로 시도하다 실패하면
> **앞에서 성공한 것까지 의심받는다.**

### 2/4 정정은 감추지 말고 이야기로

> "처음에는 4/4 로 보고했습니다. 검증 코드가 **이번에 꽂을 책 하나만** 봤기 때문입니다.
> 장면 전체를 확인하도록 고친 뒤 다시 재니 2/4 였고, 실패 원인은 M406 · M409 였습니다."

**하지 말 것**: 녹화본에서 실패한 권만 잘라내기, "거의 다 됐습니다"(측정값 없는 진행률),
아직 확정 안 된 원인을 단정하기.

## 9. 정리 (시연 후)

**터미널 A**: `Ctrl+C` → Isaac 종료. 남았는지 확인:

```bash
ps -eo pid,cmd | grep "[r]un_simulation.py"     # GPU PC 안에서
kill <PID>                                      # 남아 있으면 PID 로만
```

**터미널 B**: `Ctrl+C` (전부 함께 종료된다)

> `pkill -f run_simulation.py` 를 ssh 한 줄로 실행하면 **명령 자신이 패턴에 걸려 세션이 죽는다.**
> 반드시 PID 로 끄거나 `P="run_simu""lation.py"; pkill -f "$P"` 처럼 문자열을 쪼갠다.
> 그리고 **다른 팀원 프로세스는 절대 건드리지 않는다** — 끄기 전에 `ps` 로 확인한다.
