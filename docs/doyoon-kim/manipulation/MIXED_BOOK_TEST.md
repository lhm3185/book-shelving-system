| 항목 | 값 |
| --- | --- |
| 작성 | 2026-09-18 오전, D 김도윤 |
| 배경 | 9/17 시연에서 **트레이 책이 하나의 큰 박스로 묶여 인식**됨. 비전 담당 판단은 코드가 아니라 학습 쪽 |
| 한 것 | 색·크기가 다른 책 6종을 트레이에 놓을 수 있게 실행기를 고치고, **같은 책 6권 / 6종 섞기**를 같은 조건에서 비교 |

## 1. 인식 비교 (손목 RealSense, 640×640, 같은 홈 자세, 임계값 0.25 로 낮춰 관찰)

| --- | --- | --- |
| 박스 수 | 5 | 6 |

| 최고 신뢰도 | 0.78 | 0.72 |

원본: `results/20260918_mixed_books/same_tray_c25.jpg`, `mixed_tray_c25.jpg`

**책 종류를 바꿔도 결과가 거의 같다.** 큰 박스는 "같은 책이 붙어 있어서"가 아니다.

## 2. 그림에서 확인한 실제 원인

- 홈 자세에서 손목 카메라는 트레이를 비스듬히 본다 → 책이 **책등이 아니라 책배(종이 단면)** 로 보인다. 흰 종이 면이 줄줄이 늘어선 모습이라 **책 종류가 달라도 화면에서는 비슷하다**
- 한 화면에 **서가·트레이·로봇 팔·바닥**이 같이 들어와, 큰 박스가 트레이 전체나 서가까지 덮는다
- 학습 데이터는 서가 정면(책등) 위주 → 지금 보는 장면이 학습에 없다

## 3. 비전 담당에게 제안 (둘 중 하나, 또는 둘 다)

| 방법 | 내용 | 누가 |
| --- | --- | --- |
| **관측 자세 변경** | 트레이 **바로 위에서 내려다보는** 자세를 따로 만들어 그 자세에서만 검출 요청 (책등이 위로 보인다) | 로봇팔(D) 자세 제공 → 비전(B) 확인 |
| **트레이 장면 학습 추가** | 지금 자세·위에서 본 자세의 트레이 사진으로 학습 데이터 보강 | 촬영 D, 학습 B |

수치 합격 기준은 웹 클로드 회신대로 **6권 중 5권 이상 개별 검출, 무관한 검출 5개 이하**.

### 고친 것 (실행기)

| 항목 | 전 | 후 |
| --- | --- | --- |
| 트레이 책 원본 | 한 종류 고정 | `--book-variants` 목록을 돌려 가며 배치 |
| 에셋 방향 | 원본이 놓인 방향 그대로 | **90° 회전 조합을 시험해 세운다** (에셋마다 눕힌 것이 있어 두께 0.189 로 잡히던 문제) |
| 파지 폭·계획·꽂힘 판정 | 첫 책 치수 | **책별 치수** |
| 파지점 | AABB 중심 | **책 좌표계의 윗면 중심** (조금만 기울어도 손가락이 책을 밀어냄 — M406) |
| 파지 순간 | 그대로 붙임 | **세운 자세로 맞춘 뒤** 고정 조인트 (기울기가 서가까지 따라가 꽂힘 판정 실패) |
| 조이는 양 | 4 mm 고정 | 두께에 비례 (얇은 책을 밀어내지 않게) |
| 책 충돌 | convexHull (둥근 표지가 흔들림) | **boundingCube** |
| 칸 바닥 | 목표 z − 책높이/2 | 같은 칸이면 **실제 선반 바닥** (책 높이가 다르면 떠 있거나 파묻힘) |
| 북엔드 | 첫 책 두께 고정 | 가장 두꺼운 책 기준 + **꽂기 직전 그 책 두께로** (kinematic) |

### 시험하며 알아낸 제약

| 제약 | 내용 |
| --- | --- |
| **얇고 높은 책은 트레이에서 넘어진다** | (세운 깊이 ÷ 두께) 가 5 를 넘으면 스스로 쓰러져 칸 중심에서 3 cm 밖으로 → M411. 0.027×0.189, 0.022, 0.011 짜리가 해당 |
| **트레이 칸막이는 못 세운다** | 칸 간격 0.075 m 안에 손가락이 지나갈 폭이 없다. 칸막이를 세우면 파지 경로가 막혀 M404 |
| **아주 작은 책(높이 0.139)** | 꽂을 때 손이 서가 안으로 더 깊이 들어가 북엔드와 부딪혀 M404. 1차에서는 높이 0.22~0.24 책으로 제한 |
| 노드 칸 배정 | `manipulation_node` 는 트레이 칸 배정을 기억한다. 판을 다시 돌릴 때는 **노드도 새로 띄워야** 한다 (`mixed_book_run.sh` 가 자동으로 한다) |

## 5. 실행 방법

```bash
# 한 판 전체 (GPU PC Isaac 재시작 + 노드 재시작 + 4권 꽂기)
cd ~/ws_cobot_pjt/book-shelving-system/ros2_ws/src/shelving_manipulation/isaac_sim/tools
ROS_DOMAIN_ID=130 ./mixed_book_run.sh 4              # 6종 섞기
ROS_DOMAIN_ID=130 BOOKS=same ./mixed_book_run.sh 4   # 같은 책 6권 (비교용)

# 시연처럼 카메라까지 (GPU PC)
ROS_DOMAIN_ID=130 ~/arm/isaac/run_demo_gpu.sh --book-variants mixed

# 인식 한 장 (창 없이, 박스 수·크기 출력)
python3 tray_detect_shot.py --conf 0.25 --out /tmp/b1_demo/tray.jpg
```

책 종류를 바꾸려면 `--book-variants prim이름1,prim이름2,...` (레벨 `/World/books` 에 있는 이름). 에셋은 `dataset/usd_v2` 에 112개.
