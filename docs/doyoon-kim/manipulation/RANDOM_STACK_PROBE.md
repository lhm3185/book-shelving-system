## 1. 시험 방법

레벨 v5 에서 **트레이를 치우고** 데크 위에 책 6종을 무작위로 놓는다. 배치 8회.

| 배치 방식 | 내용 |
| --- | --- |
| `flat` | 눕혀 놓기 (표지가 위) |
| `stack` | 앞 책 위에 겹쳐 쌓기 |
| `lean` | 세워 놓기 (트레이 때와 같은 자세, 지지대 없음) |

각 배치마다 ① 여러 각도에서 사진 + 정답 상자(Isaac 주석기) ② 책마다 **위에서 내려 잡는 파지 계획** 을 세운다.
계획 판정 기준은 시연 경로와 같다: 그리퍼 폭, IK 해(M401), 경로 관절 변화 ≤ 0.12 rad(M402), 그리고 **다른 책이 위를 덮고 있는지**.

```bash
# GPU PC
ISAAC_ENTRY=~/arm/isaac/random_stack_probe.py ~/arm/isaac/run_capture.sh \
    --layouts 8 --views 25 --out ~/stack_probe
```

## 2. 인식 — 트레이용으로 학습한 모델이 무작위 배치에서도 어느 정도 된다

사진 200장, 정답 상자 6,507개로 `book_tray_best.pt` 를 그대로 평가했다.

| | 트레이 장면 (학습 분포) | **무작위·쌓인 배치** |
| --- | --- | --- |
| mAP50 | 0.926 | **0.783** |
| mAP50-95 | 0.787 | **0.624** |
| 정밀도 | 0.951 | 0.903 |
| 재현율 | 0.868 | **0.708** |

**[판단] 데이터를 처음부터 다시 만들 필요는 없다.** 학습 분포 밖인데도 mAP50 0.78 이 나온다.
재현율이 0.87 → 0.71 로 떨어지는 것이 실제 손실이고, 이는 **쌓여서 가려진 책과 눕혀서 표지만 보이는 책**에서 나온다.
2차에서는 이 두 경우의 사진만 보태면 된다 (전체 재촬영이 아니라 보강).

## 3. 파지 계획 — 48건 중 29건(60%) 성공

| 실패 사유 | 건수 | 뜻 |
| --- | --- | --- |
| **IK 해 없음 (M401)** | 8 | 로봇이 정지한 자리에서 팔이 닿지 않는 위치. **AMR 이 자리를 잡아 주면 풀리는 문제** |
| **잡을 변이 그리퍼보다 넓다** | 5 | 눕힌 책을 위에서 잡으면 **가로 15~17 cm** 를 물어야 한다. 그리퍼 최대 8 cm → **원리상 불가** |
| 경로 관절 변화 초과 (M402) | 4 | 손목이 뒤집히는 해가 나와 경로가 끊김. 시드·자세 제약으로 풀 수 있는 계획 문제 |
| 쌓여서 위가 덮임 | 2 | 위 책을 먼저 치워야 한다 (순서 문제) |

### 여기서 나오는 2차 과제 세 가지

1. **눕힌 책은 위에서 못 잡는다** — 원리상 막힌 유일한 항목이다. 옆에서 집기, 가장자리로 밀어 세우기, 흡착 중 하나를 골라야 한다. 이것이 2차의 핵심 설계 결정이다
2. **쌓인 더미는 순서가 필요하다** — 위에서부터, 가려지지 않은 책만. 지금 코드에 "덮임" 판정은 넣어 뒀다
3. **닿지 않는 위치는 AMR 과 같이 푼다** — 파지 실패가 아니라 배치 문제다. 8건 모두 로봇이 고정된 자리에서 생겼다

## 4. 트레이와의 연결

`MIXED_BOOK_TEST.md` 에서 나온 제약과 이어진다.

> 트레이에 책을 세워 담는 전제는 얇은 책에서 성립하지 않는다 (세운 깊이 ÷ 두께 > 5 이면 넘어짐, 칸 간격 0.075 m 라 칸막이 추가 불가).
> 실제 도서관 반납 카트가 책을 **눕혀 쌓는** 이유가 여기에 있다.

그런데 눕혀 쌓으면 **위에서 내려 잡는 지금 방식으로는 집을 수 없다**(3절). 즉 두 사실이 한 문제를 가리킨다:
**담는 방식과 집는 방식은 같이 정해야 한다.** 2차의 첫 결정이 여기다.
