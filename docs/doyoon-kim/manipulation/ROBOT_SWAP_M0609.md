# 로봇 교체 (nova-carter + M0609) — 영향 정리와 필요한 것

| 항목 | 값 |
| --- | --- |
| 작성 | 2026-09-18 저녁, D 김도윤 |
| 상황 | 매니퓰레이터를 **ridgeback + Franka → nova-carter + M0609** 로 바꿀 예정. 결합 에셋은 완성 후 전달 예정 |
| 결론 | **1차 시연(9/21)은 지금 로봇으로 하고, 교체는 그 뒤에 하는 것을 권합니다.** 준비 자체는 지금부터 할 수 있습니다 (설정 파일이 이미 있음) |

## 1. 다행인 것 — M0609 설정이 이미 있다

실행에 필요한 M0609 Lula 입력과 결합 로봇 USD는 저장소의
`isaac_sim/assets/cobot3_ws/isaacpjt/M0609/` 아래에 함께 둡니다.

| 있는 것 | 내용 |
| --- | --- |
| `descriptor/m0609_description.yaml` | Lula 로봇 기술서 (관절 `joint_1`~`joint_6`, root `base_link`, 충돌 구) |
| `doosan-robot2/urdf/m0609.urdf` | Lula용 URDF (관절 속도 한계 2.618~3.927 rad/s) |
| `doosan-robot2/urdf/m0609_isaac_sim/` | 결합 월드가 참조하는 M0609 USD |
| `onrobot_rg2/urdf/onrobot_rg2/` | 결합 월드가 참조하는 **OnRobot RG2** USD |

Isaac 이 기본 제공하는 motion_generation 설정에는 **Doosan 이 없습니다** (Franka·FR3·UR·Kawasaki·Denso·Festo·Techman·Kuka·Fanuc 뿐). 위 파일들이 그 자리를 대신합니다.

## 2. 그대로 쓰는 것 / 다시 해야 하는 것

| 항목 | 상태 |
| --- | --- |
| ROS 인터페이스 (`/place_book`, `/manipulation/sim/*`, `/robot/status`) | **그대로** |
| 작업 단계·오류 코드 (M401~M412), 판정 기준 | **그대로** |
| FSM·비전과의 계약 (arm_base_link, AABB 중심, yaw +90°) | **그대로** |
| 동작 프리미티브 구조 (MoveJoint·JointPath·SetGripper·Sequence) | **그대로** |
| IK·RMPflow 설정 로드 | **바꿔야 함** — Isaac 내장 "Franka" 설정 → 위 M0609 파일 |
| 관절 이름·개수 | **바꿔야 함** — `panda_joint1~7` (7축) → `joint_1~6` (**6축**) |
| 그리퍼 | **바꿔야 함** — Franka ParallelGripper(0~80 mm) → RG2(관절식, `finger_joint` 각도 제어) |
| 로봇 prim 경로·베이스 관절 | **바꿔야 함** — `/World/ridgeback_franka`, `dummy_base_x/y` → nova-carter 구조 |
| 팔 기준 프레임 | **바꿔야 함** — `panda_link0` → M0609 `base_link` |
| **검증된 좌표 전부** | **다시 측정** — 트레이 6칸, 서가 4칸, 관측 자세, 삽입 깊이, 북엔드 간격 |

### 특히 큰 것 두 가지

1. **6축이 됩니다.** Franka 는 7축이라 같은 손 자세를 여러 관절 조합으로 만들 수 있었지만, 6축은 해가 하나뿐입니다. 지금 4/4 가 나오는 경로가 6축에서도 IK 해가 있는지는 **다시 확인해야** 합니다. 특히 "책을 90° 눕혀 끼우는" 손목 자세가 관건입니다.
2. **그리퍼가 각도식입니다.** RG2 는 평행 조가 아니라 링크로 벌어져서, 지금 코드의 "손가락 하나당 몇 m" 지령을 **각도 → 폭 환산**으로 바꿔야 합니다.

**정정 (2026-09-18 밤)**: 처음에 "RG2 개구가 넓어 눕힌 책 파지 제약이 완화된다" 고 적었는데 **틀렸습니다.**

| | 개구 | 눕힌 책 긴 변 |
| --- | --- | --- |
| Franka | 8 cm | 15~17 cm → 불가 |
| **RG2** | **10~11 cm** | 15~17 cm → **여전히 불가** |

8 → 11 cm 는 늘어난 것이 맞지만 필요한 값(15~17 cm)에 못 미칩니다. 두께 방향(2~4.5 cm)은 Franka 로도 이미 됐고, 막힌 이유는 그리퍼 폭이 아니라 **쌓여 있으면 옆면에 손가락 넣을 공간이 없다**는 것이었습니다.
→ **눕힌 책 파지의 세 선택지(옆에서 집기 / 밀어 세우기 / 흡착)는 로봇을 바꿔도 그대로 남습니다.**

## 3. 에셋 받을 때 같이 알려주시면 좋은 것

1. 로봇 prim 경로 (예: `/World/nova_carter_m0609`)
2. **팔이 베이스에 붙은 위치·자세** (데크 기준 mount transform) — 이게 있으면 좌표 재측정을 반만 해도 됩니다
3. 그리퍼 모델 확정 (RG2 맞는지) 과 개구 범위
4. 카메라 장착 위치 (손목인지, 어느 링크인지)
5. 베이스 고정 방식 (nova-carter 는 차동 구동 — 시뮬에서 정지시키는 방법)

## 4. 일정 제안

| 시점 | 내용 |
| --- | --- |
| ~9/21 | **1차 시연은 지금 로봇(ridgeback+Franka)으로.** 4/4·2/2 가 검증된 상태 |
| 9/22~23 | 교체 작업: 설정 로드 경로 변경 → 6축 IK 확인 → 그리퍼 환산 → 좌표 재측정 |
| 9/24~ | 재검증(트레이 6칸 × 서가 4칸), FSM 재연결, 필요하면 인식 데이터 보강 |

교체 자체는 **설정 파일이 있어 반나절~하루** 규모로 봅니다. 다만 **좌표 재측정과 재검증이 그보다 오래** 걸립니다 (지금 좌표는 Franka 기준으로 맞춰 둔 값이라 전부 다시 나와야 합니다).

에셋이 나오면 바로 1~2번(설정 로드, 6축 IK 확인)부터 해 보겠습니다. 그건 좌표 없이도 됩니다.
