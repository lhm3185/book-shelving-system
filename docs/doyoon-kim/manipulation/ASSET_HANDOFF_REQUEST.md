# 결합 매니퓰레이터 에셋 — 받을 때 같이 필요한 것 (로봇팔 담당 → AMR 담당)

| 항목 | 값 |
| --- | --- |
| 작성 | 2026-09-19, D 김도윤 |
| 배경 | 결합은 **AMR 담당이 직접** 하기로 정리됐습니다. 우리가 만든 것은 클라우드 카터 원본을 참조해 라이다·카메라 구성이 빠져 있어 실사용이 안 됐습니다 |
| 목적 | 에셋을 받는 즉시 로봇팔 코드를 붙일 수 있도록, **딱 네 가지**만 확인해 주시면 됩니다 |

## 우리 쪽 준비 상태

로봇팔 코드는 이미 **로봇 이름을 한 파일에서만 바꾸면 되도록** 정리해 두었습니다
(`simulation/isaac/config/robot_profiles.py`). 아래 네 가지만 채우면 바로 돌립니다.

## 1. prim 경로 4개

```
articulation root      예) /World/carter_m0609
팔 베이스 링크          예) .../arm/m0609/base_link      ← 모든 좌표의 기준
손목 플랜지 링크        예) .../arm/m0609/link_6          ← 파지 고정 조인트를 매답니다
손목 카메라 prim        예) .../angle_bracket/realsense_d455/RSD455/Camera_OmniVision_OV9782_Color
```

USD 를 주시면 저희가 직접 읽어서 확인할 수도 있습니다. **경로만 알려주셔도 됩니다.**

## 2. 관절 이름이 그대로인지

```
팔     joint_1 ~ joint_6
그리퍼 left_inner_knuckle_joint / right_inner_knuckle_joint
```

> **주의**: `finger_joint` 은 이름과 달리 **명령해도 거의 안 움직입니다** (실측 0.0008 rad).
> 실제로 도는 것은 양쪽 knuckle 입니다 (0.256 / 0.300 rad). 혹시 그리퍼를 다시 임포트하셨다면
> 이 관계가 달라질 수 있으니 알려 주세요.

## 3. 팔이 카터의 어디에, 어느 높이에 붙었는지

저희가 만들 때 겪은 것이라 참고로 남깁니다 (같은 곳에서 막히실 수 있습니다):

| 사실 | 값 |
| --- | --- |
| 카터 AABB 윗면 0.554 는 상판이 아니라 **XT_32 3D 라이다 꼭대기** | |
| 장착점 (0,0) 바로 아래는 **front_RPLidar** (윗면 0.436, 주변 상판 0.430) | |
| 뒤쪽 평평한 상판 0.464 위에는 **XT_32**(x −0.389~−0.180)가 서 있음 | |
| M0609 받침판 크기 | **20.6 cm** |

→ **카터 상판에 평평한 20 cm 자리가 없습니다.** 저희는 팔 높이를 유지하고 사이를 어댑터로 채웠습니다.

그리고 **재생하자마자 로봇이 넘어지거나 날아간다면** 십중팔구 다음 둘입니다:

1. **고정 조인트 로컬 좌표** — 조인트의 `localPos0` 은 바디의 **프레임 원점** 기준입니다.
   `chassis_link` 의 프레임 원점은 (0,0,0) 인데 AABB 중심은 (−0.234, 0, 0.315) 라, AABB 중심으로
   잡으면 **39 cm 어긋나** 재생 순간 팔이 끌려가며 로봇이 튕겨 나갑니다. 스케일을 키우면 더 멀리 납니다.
2. **팔 드라이브 목표** — URDF 임포트가 `joint_3`·`joint_5` 목표를 **90°** 로 써 두는데 시작 자세는 0° 입니다.
   강성을 높여 두면 재생 순간 팔을 85° 확 끌어당겨 로봇을 넘어뜨립니다. 목표를 시작 자세에 맞추면 해결됩니다.

확인 도구를 만들어 두었으니 그대로 쓰셔도 됩니다:

```bash
cd ~/book-shelving-system
# 실제로 재생해서 이동·기울기·팔 어긋남을 잽니다 (정지 상태 검사로는 안 잡힙니다)
ISAAC_ENTRY=simulation/isaac/tools/settle_test_carter.py ./scripts/run_isaac_tool.sh --usd <에셋>.usd
# 상판 높이 지도 + 센서 발자국
ISAAC_ENTRY=simulation/isaac/tools/probe_carter_deck.py ./scripts/run_isaac_tool.sh --usd <에셋>.usd
```

통과 기준: **기울기 1° 미만, 팔–베이스 어긋남 5 mm 미만** (저희 마지막 값은 0.15° / 1.4 mm).

## 4. 다른 PC 에서도 열리는지

USD 가 팔을 **절대경로**로 참조하면 다른 PC 에서 팔이 통째로 빠집니다. 상대경로로 바꾸는 도구가 있습니다:

```bash
ISAAC_ENTRY=simulation/isaac/tools/relativize_usd_refs.py ./scripts/run_isaac_tool.sh --root <에셋 폴더>
```

바로 공유하고 시연 범위를 다시 정해야 합니다.
