## 0. 이 문서를 읽는 웹 클로드에게

B-1팀 "도서 자동 배가 시스템"(10일, 시뮬 전용, Isaac Sim 5.1 + ROS 2 Jazzy)의 하위 작업 기록이다.
이 문서는 **CLI 클로드가 실제로 실행하고 검증한 결과**만 담는다. 추정과 사실을 구분해 표기했다.
조언이 필요한 지점은 6절에 모아 두었다.

---

## 1. 무엇을 만들었나

블렌더에서 책을 자동 촬영해 **라벨이 이미 붙은** 학습 데이터를 생성하는 파이프라인.

핵심은 **사람이 바운딩 박스를 그리지 않는다**는 점이다. 블렌더가 책의 3D 형상과 카메라 파라미터를 알고 있으므로 라벨을 기하 계산으로 만든다. 정확도는 블렌더 자체 투영 함수와 대조해 **오차 0.00px**로 검증했다.

한 장당 산출물:

| 파일 | 내용 | 검증 |
| --- | --- | --- |
| `images/*.png` | 컬러 640×480 | — |
| `depth/*.png` | 16비트 PNG, **밀리미터**, 65535=배경 | 라벨 거리와 비교해 오차가 책 대각선 절반 이내 확인 |
| `mask/*.png` | 알파 마스크 | 실루엣 기준 bbox 산출에 사용 |
| `labels/*.json` | bbox, 6D 자세(OpenCV 규약), K, 랜덤화 기록 | 투영 오차 0.00px |

랜덤화 항목: 카메라 방위·고도·거리·롤, 책 자세(회전 후 바닥에 재안착), 조명 1~3개(방향·세기·색온도), 배경색·밝기, 표지·책장·띠·바닥 색과 거칠기.

---

## 2. 확정한 규약

| 항목 | 값 | 근거 |
| --- | --- | --- |
| 가로 화각 | **90.5°** | Isaac Sim USD 손목 카메라 실측값. 학습·추론 화각 불일치가 성능에 직결 |
| 해상도 | **640×480** | 브리프 권고 + RealSense D435 기본. **Isaac Sim은 현재 640×640이라 변경 요청 상태** |
| 자세 규약 | OpenCV (+Z 앞, +X 오른쪽, +Y 아래), 단위 m | 학습 프레임워크 관례 |
| 깊이 규약 | uint16 mm, 65535=배경 | RealSense와 동일. EXR은 5.x에서 멀티레이어만 지원돼 OpenCV로 못 읽음 |
| bbox 기준 | **마스크 실루엣** | 3D 박스 투영은 평균 1.03배 크고 IoU 0.967 (측정값) |

## 3. 에셋 현황

| 구분 | 내용 |
| --- | --- |
| 로컬 에셋 | `book.blend`, `Book.blend`(2.5m → 0.22m 정규화), `Books.blend`(표지·책장 분리 → 합침), `books.fbx`(UDIM 텍스처 연결), `OldBook001.fbx` |
| CC0 에셋 | Poly Haven `book_encyclopedia_set_01`(20권), `decorative_book_set_01`(표지 텍스처 80종+) |
| 보류 | `Black_shelf/shelf.blend` — 서가. CP3(배가 위치 인식)용 |

**라이선스 확인 사항**
- Poly Haven = CC0. 상업적 이용·수정·AI 학습 모두 허용, 출처 표기 의무 없음
- CGTrader에는 **`Royalty Free No Ai License`** 가 있고 이는 **머신러닝 학습 사용을 금지**한다. 해당 에셋은 사용 불가
- CGTrader는 봇 차단 + 로그인 필요라 CLI에서 자동 확인·다운로드가 불가능하다. 사람이 확인해야 함

## 4. 현재 상태

- 파이프라인 검증 완료, 단위 테스트 20개 통과 (블렌더 없이 실행 가능한 순수 계산부)
- 화각 39.6°로 생성한 692장은 **폐기 보관**(`dataset_fov39_old`) — 화각 불일치 발견으로 재생성 결정
- **화각 90.5°로 전체 재생성 진행 중**: 21권 × 40장 ≈ 840장
- 책별 USD 내보내기 동작 확인 (Isaac Sim 투입 가능)

성능 참고(개인 PC, GPU 없음, EEVEE, 640×480, 샘플 32):
장당 컬러 1.08초, 컬러+깊이 1.36초, 컬러+깊이+마스크 약 1.7초. GPU PC에서는 훨씬 빠를 것으로 예상(미측정).

## 6. 웹 클로드에게 묻고 싶은 것

1. **도메인 차이 대응**: 학습은 블렌더, 추론은 Isaac Sim이다. 화각은 맞췄으나 렌더러가 다르다.
   Isaac Sim Replicator로 데이터를 다시 만드는 게 맞나, 아니면 블렌더 데이터에 도메인 랜덤화를 더 넣는 쪽이 현실적인가?
   (브리프상 "합성 데이터 생성"은 원래 범위 밖이었으나 팀 판단으로 진행 중이며, 남은 기간은 10일 중 후반부다)
2. **데이터 규모**: 21권 840장으로 시작한다. 시뮬-투-시뮬이고 에셋이 고정이라면 이 정도로 충분한가,
   아니면 3000~5000장이 필요한가?
3. **자세 추정 방식**: 학습 없이 마스크+깊이 PCA로 파지 자세를 계산하려 한다.
   책이 겹쳐 있는 CP1 상황에서 이 방식의 한계가 무엇일지, 보완책이 있는지?
4. **평가 지표**: 파지 성공률 외에 발표·보고서에 넣을 만한 정량 지표로 무엇이 적절한가?
