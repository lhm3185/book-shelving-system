## 먼저 — 동기화로 v2.md 를 날린 것

`docs/` 를 `rsync --delete` 로 보내는 설계가 GPU PC 가 쓴 파일을 지웠다. 합의한 규칙
(`gpu_vN.md` 를 메인 PC 에 scp)을 그대로 따른다. **메인 PC 는 작업 시작 시 `docs/web_claude/gpu_*.md` 를 확인한다.**

## 1. 원점 문제 — 파지점에 translation 을 그대로 쓰는 곳이 있나

| 코드 | 결과 |
| --- | --- |
| `estimate_pose.py` | **안전.** 159~160행에서 `bbox_local` 중심을 `T_cam_obj` 로 옮겨 비교한다. 중심 오차 5.23mm 는 유효 |
| `check_labels.py` | **원점을 그대로 썼다 → 수정함.** 깊이 비교를 바운딩박스 중심 기준으로 바꿨다. 틀린 CHECK 가 사라져야 한다 |
| 로봇팔 코드 (`~/arm`) | 라벨을 읽지 않는다. 다만 **계약상 "책 중심"을 받으므로** 비전→팔 연결 시 bbox 중심을 넘겨야 한다 |
| 선반 데이터 (`dataset_shelf`) | **원점이 바닥 중심이다.** translation 은 선반 밑면 위치다. 중심이 필요하면 `bbox_local` 로 보정할 것 |

## 2. 도메인 갭 측정을 GPU PC 에서 할지

**지금은 보류.** 비전 담당에게 인계한 필수 과제이고, 측정하려면 통합 Stage(9/18 Reference 통합 예정)와
손목 카메라 설정이 확정돼야 한다. **오늘 GPU PC 의 Isaac Sim 은 로봇팔 파지·배치 검증에 쓴다.**

## 3. 스크립트 수정 — 메인 PC 에 반영함 (동기화로 넘어간다)

| 파일 | 수정 | 확인 |
| --- | --- | --- |
| `export_yolo.py` | 여러 권 장면은 **장면(이미지) 단위** 분할 | 로컬 80장면 → 64/8/8 (예전엔 전부 train) |
