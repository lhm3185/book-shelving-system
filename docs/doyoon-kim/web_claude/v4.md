## 1. 조사 결과 (Isaac Sim 5.1.0 공식 문서 기준)

### 1-1. 번들 로봇팔 목록에 **Doosan 은 없다** (확인됨)

Isaac Sim 5.1.0 에 기본 포함된 매니퓰레이터는 다음과 같다.

Franka(Panda, FR3), Universal Robots(UR3/3e/5/5e/10/10e/16e/20/30), Kuka(KR210),
Fanuc(CRX10IAL 등), Techman(TM12), Kawasaki(RS 시리즈), Kinova(Gen3, Jaco2),
Flexiv(Rizon4), Denso(Cobotta Pro), Yaskawa, Ufactory(xArm6/7, lite6), Unitree Z1 등.

**Doosan M0609 은 목록에 없다.** URDF 를 직접 임포트하는 것이 정상 경로다.
현재 팀은 이미 수업 자료의 M0609 URDF/USD 로 Lula IK 픽앤플레이스를 성공시킨 상태다.

또한 **Lula RMPflow 설정도 Doosan 용은 제공되지 않는다** (Franka, UR, Kuka, Fanuc, Techman 등만 제공).
NVIDIA 가 만든 Doosan 예제·cuMotion 설정도 찾지 못했다(미확인이지만 부정적).

### 1-2. Surface Gripper 는 5.1 에 존재하고, 우리 조건에 맞는다 (확인됨)

- 확장 `isaacsim.robot.surface_gripper`, 기본 활성화
- 5.x 에서는 **USD prim** 으로 생성한다 (`Create > Robots > Surface Gripper`)
- 동작 방식: 잡는 순간 그리퍼 바디와 대상 사이에 **D6 조인트를 만들어 붙인다**
  → 브리프가 지시한 **"마찰 튜닝 대신 파지 시 fixed joint 부착"** 과 정확히 일치한다
- 주요 파라미터: `maxGripDistance`(잡히는 거리), `coaxialForceLimit`(축방향 이탈 한계),
  `shearForceLimit`(횡방향), `retryInterval`(재시도 간격)
- 파이썬 API: `acquire_surface_gripper_interface()` → `open_gripper`, `close_gripper`,
  `set_gripper_action`, `get_gripper_status`, `get_gripped_objects` (batch 변형 있음)
- **제약(확인됨)**: 잡을 대상에 Articulation Root 가 있으면 PhysX 오류로 조용히 실패한다.
  **책은 순수 Rigid Body + 충돌체여야 한다.**

### 1-3. NVIDIA 자체 예제가 전부 흡착 기반 평면 파지다 (확인됨)

- **UR10 + 흡착 그리퍼** USD 가 Surface Gripper prim 을 포함한 채로 제공되고,
  차동 IK 로 구동되는 픽앤스택 데모가 함께 온다
- **UR10 Bin Stacking**(Cortex 튜토리얼): 흡착으로 통을 컨베이어→팔레트로 옮긴다
- Isaac Lab 에도 흡착 그리퍼 스태킹 과제가 포함되어 있다
  (`Isaac-Stack-Cube-UR10-Short-Suction-IK-Rel-v0` 등)

**책처럼 얇고 납작한 물체를 집는 NVIDIA 공식 예제는 없다**(미확인). 다만 위 예제들이
"윗면이 평평한 물체를 위에서 흡착"하는 패턴이라 가장 가깝다.

### 1-4. 번들 그리퍼에 **OnRobot RG2 는 없다** (확인됨)

Robotiq 2F-85/2F-140/Hand-E, Schunk EGK/EGU, Shadow Hand, Allegro, Franka Hand,
xArm/lite6 그리퍼 등이 제공된다. **RG2/RG6 는 없다** — 수업 URDF 가 유일한 출처다.
참고로 Robotiq 2F-85 는 평행 링크가 따라 움직이지 않는 알려진 버그가 있다(확인됨).

## 2. 현재 판단

### 2-1. 로봇팔: **M0609 유지를 권한다**

| 근거 | 내용 |
| --- | --- |
| 이미 동작한다 | URDF 임포트, Lula IK, 그리퍼 개폐, 픽앤플레이스까지 검증된 상태 |
| 교체 비용 | 다른 팔로 바꾸면 IK 설정·좌표계·도달범위를 처음부터 다시 잡아야 한다 |
| 남은 기간 | 10일 중 3일 경과. 바꿀 시점이 아니다 |
| 과제 성격 | 시뮬 전용이므로 "실물 M0609 를 쓴다"는 제약이 아니라 **수업 자산을 활용**하는 선택 |

**대안이 필요한 경우**: RMPflow(장애물 회피 궤적)나 cuMotion 을 쓰고 싶다면
UR10e 나 Franka 로 바꾸는 편이 낫다. 이들은 설정이 기본 제공된다.
다만 현재 계획은 Lula IK + 직선 보간이고, 브리프도 그 수준을 요구한다.

### 2-2. 그리퍼: **Surface Gripper(흡착) 를 권한다**

| 근거 | 내용 |
| --- | --- |
| 브리프 일치 | "마찰 기반 정밀 파지 물리 튜닝"이 **범위 밖**이고 "Surface Gripper 또는 fixed joint"를 쓰라고 명시 |
| 물리적 타당성 | 책은 두께 2~4cm 이고 트레이에 붙어 쌓인다. **평행 조를 넣을 옆 공간이 없다** |
| 실제 사례 | 도서관 자동화 설비도 평면 흡착을 쓴다 |
| NVIDIA 예제 | 흡착 기반 평면 파지 예제가 그대로 존재해 참고 가능 |
| 구현 난이도 | 개폐 두 동작. 마찰·힘 튜닝 불필요 |

**평행 조(RG2)의 문제**: 겹쳐 쌓인 책의 옆면을 잡으려면 손가락이 들어갈 틈이 필요한데,
트레이에 밀착된 상태에서는 확보되지 않는다. 한 권만 떨어져 있을 때만 가능하다.

### 2-3. 절충안

시연 장면에 따라 **둘 다 쓸 수도 있다.**
- 트레이에서 꺼낼 때(CP1): 흡착 — 위에서 표지를 붙잡는다
- 서가에 꽂을 때(CP3): 흡착 유지. 브리프 권고대로 **빈 슬롯에 놓기(drop-in)** 이므로 밀어 넣을 필요가 없다

다만 **그리퍼를 두 개 다는 것은 권하지 않는다.** 복잡도만 늘고 10일 안에 이득이 없다.

## 3. 확인이 필요한 사항 (컨펌 요청)

1. **M0609 유지가 맞나?**
   RMPflow·cuMotion 을 포기하는 대가로 이미 동작하는 자산을 쓰는 선택이다.
   장애물 회피가 CP3(서가 주변 충돌 회피)에서 필요해질 수 있는데, 이때 Lula IK + 직선 보간으로
   충분할지, 아니면 지금 UR10e 로 바꾸는 편이 나을지 판단이 필요하다.

2. **Surface Gripper 가 맞나?**
   "흡착으로 책을 집는다"가 도서관 자동화 맥락에서 설득력 있는 선택인지,
   아니면 평행 조로 한 권씩 세워 집는 그림이 심사에서 더 나은지.

3. **시각적 표현**
   Surface Gripper 는 물리적 형상이 없다. 수업 RG2 모델을 붙여 둔 채 실제 파지는 흡착으로 처리할지,
   흡착 컵 형상을 따로 만들어 붙일지. 후자는 시연 영상의 설득력이 올라가지만 작업이 늘어난다.

4. **책 물성 제약**
   Surface Gripper 는 대상에 Articulation Root 가 있으면 실패한다. 책은 순수 Rigid Body 여야 한다.
   Isaac Sim 담당자에게 전달할 사항인데, 다른 제약이 더 있을지.

## 4. 참고 — 구현 시 쓸 것 (확인됨)

```python
from isaacsim.robot.manipulators.grippers import ParallelGripper, SurfaceGripper
from isaacsim.robot.manipulators.manipulators import SingleManipulator
from isaacsim.robot.surface_gripper import _surface_gripper
```

- 구형 `omni.isaac.*` 이름은 5.x 에서 경고와 함께 동작하지만 **6.0 에서 제거**된다. 새 이름으로 작성한다
- 참고 예제: `isaacsim.robot.manipulators/ur10_pick_up.py`, `universal_robots/pick_place.py`,
  `ur10e/gripper_control.py`
- URDF 재임포트 시 링크·조인트·메시 이름에 특수문자·선행 숫자·밑줄이 있으면 실패한다
- Surface Gripper 권장 초기값: `maxGripDistance` 1~2cm, 힘 한계는 넉넉히, `retryInterval` 0.1~0.5s
