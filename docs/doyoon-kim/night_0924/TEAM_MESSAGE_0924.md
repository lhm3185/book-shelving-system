# 오늘 팀에 보낼 메시지 (연휴 시작 전)

**목적**: 연휴 뒤 복귀 첫날에 통합할 수 있게, 오늘 세 가지만 맞춰 둔다.
**보내는 곳**: 팀 단톡/슬랙 · **길이**: 답이 한 줄이어도 되게 썼다.

---

```
연휴 시작 전에 세 가지만 맞춰 두고 싶습니다. 짧게 답만 주셔도 됩니다.


■ 1. 제출물 기준 브랜치가 어디인가요?

최종 산출물이 main 기준인지, 통합 브랜치를 따로 파는지에 따라
연휴 동안 저희가 할 일이 달라집니다.

참고로 지금 브랜치들을 재 보니 refactor/project-layout 이
main 을 전부 포함하고 147 커밋 앞서 있습니다 (nav2 · fine docking 포함).
이게 사실상 다음 main 인가요?


■ 2. 인터페이스를 연휴 동안 동결하면 어떨까요

복귀하면 바로 제출이라 통합할 시간이 하루 정도입니다.
아래 셋만 연휴 동안 안 바꾸면 복귀 첫날 붙이기가 훨씬 쉬워집니다.

  - /place_book 액션의 요청·결과 필드와 오류 코드
  - TargetSlot(빈칸) 메시지 필드
  - 좌표 프레임 = arm_base_link

바꿔야 할 사정이 있으면 미리 말씀해 주세요.


■ 3. 비전팀께 한 가지 요청

TargetSlot 에 "측정 시점의 로봇 베이스 자세"를 넣어 주실 수 있을까요?

스캔하는 자리와 삽입하는 자리가 다르면 그 사이 차체가 움직인 만큼
좌표가 틀어지는데, 지금은 저희가 그걸 알 방법이 없습니다.
필드 두 개면 됩니다 (Pose + 프레임 이름). 안 채우셔도 안 깨지게
기본값을 비워 두는 형태로 제안드립니다.

상세는 저장소에 정리해 뒀습니다:
  docs/doyoon-kim/proposals/interfaces/


■ 그리고 부탁 하나 — 발표 영상

최종 발표에 각 파트 시연 영상을 이어 붙이려고 합니다.
비전 검출 화면과 AMR 주행(RViz 포함) 영상이 있으면 공유해 주세요.

**안 주셔도 됩니다** — 저희 쪽에서 찍은 것으로 채울 수 있습니다.
각 팀이 직접 찍은 것이 더 정확할 테니 여쭙는 것입니다.
연휴 중 여유 있을 때 주셔도 되고, 복귀 후에 주셔도 됩니다.

저희 로봇팔 구간 영상은 오늘 올려 두겠습니다.


■ 참고 — 레벨 콜리전

레벨의 콜리전 근사 때문에 꽂힌 책이 2~3° 기울고 선반 판 위 18 mm 에
뜨는 것을 찾았습니다. 지금은 **레벨 원본을 건드리지 않고** 런타임에서만
교정했습니다 (기울기 3.5° → 0.4°).

원본 수정 제안은 문서로 남겨 뒀으니 복귀 후에 같이 보시죠:
  docs/doyoon-kim/proposals/level_collision.md
```

## 왜 이 넷인가

| | 안 보내면 |
|---|---|
| 1 기준 브랜치 | 연휴 내내 **가정 위에서** 통합 준비를 하게 된다 |
| 2 인터페이스 동결 | 복귀 첫날 계약이 바뀌어 있으면 하루로 못 붙인다 |
| 3 `base_pose` | 복귀 후 요청하면 **그때부터** 작업이 시작된다 |
| 4 영상 | 발표에 우리 구간밖에 못 넣는다. **오늘 안 물으면 못 받는다** |

## 주의

- **답을 강제하지 않는다.** 연휴다. "한 줄만" 이라고 쓴 것이 그래서다
- 3번은 **안 해줘도 안 깨지는 형태**로 제안했다. 부담을 줄여야 받아들여진다
- 레벨은 **안 건드렸다는 사실**을 먼저 쓴다. 공용 자산을 말없이 고친 것으로 오해받지 않게
