# 트레이 + 트레이 책 (팀원 전달용)

`Final_Level_Library.usdc` 의 `/World/tray_books` 를 그대로 뽑은 것이다.
레벨을 평탄화한 뒤 **필요 없는 것만 지웠다** — 남은 스펙은 원본 그대로라
UV·좌표·머티리얼 파라미터가 손대지 않은 채 보존된다.

```
tray_set.usd     트레이 1 + 책 5 (+ 바인딩된 머티리얼 7)
textures/        베이스컬러 5장. usd 안에서 ./textures/… 상대경로로 건다
tray_set.usdz    한 파일 묶음 (보기·전달용, 편집에는 불편하다)
```

**좌표는 원본 레벨의 월드 좌표 그대로다** (트레이 출발 자리). 다른 레벨에
가져다 쓰면 그 자리에 놓이니, 필요하면 `/World/tray_books` 를 통째로 옮기면 된다.

## 깨졌는지 확인하는 법

```bash
python3 -c "
from pxr import Usd, UsdUtils
L, A, U = UsdUtils.ComputeAllDependencies('tray_set.usd')
print('레이어', len(L), '에셋', len(A), '못 찾음', U)"
```

**`못 찾음` 이 비어 있어야 한다.** 만든 시점 기준으로 비어 있었고,
원본과 AABB 차이는 **0.0000 mm** 였다.
