# attic — **지금 안 쓰지만 지우지 않는 것**

2026-09-24 · 웹 클로드 v41 회신 §5 의 기준에 따라 만든 자리.

> **문제를 보이게 하는 것은 남기고, 문제를 가리는 것은 지운다.**
> 그리고 **지금 안 쓰는 것은 지우지 말고 격리한다** — 지우면 6일 안에 또 만든다.

여기 있는 것은 **본체가 import 하지 않는다.** 시험도 여기서 돈다(`pytest attic/`).
쓸 일이 생기면 `controllers/` 로 옮기고 본체에서 부르면 된다.

| 파일 | 무엇 | 왜 여기 있나 |
|---|---|---|
| `record_views.py` | 녹화 시점을 장면에서 파생 (front/side/top/shelf/wide) | 다각도 녹화를 보류했다. 9/27~28 녹화 때 쓸 수 있다 |
| `hand_drift.py` | 손 기준 책 어긋남 — 원점·형상중심·쥔점 세 기준을 가른다 | 406 판정을 쥔점 기준으로 바꿀 때 쓴다. 지금 본체는 안 쓴다 |

**지운 것과 여기 있는 것의 차이**: `sweep_retry.py` 는 지웠다. 그건 안 되는 것을
**되는 것처럼 보이게** 만들어서, 어제 동작이 사라진 것을 아무도 못 보게 했다.
여기 둘은 **드러내는 쪽**이라 남긴다.
