# M0609 Lula 입력 파일

이 디렉터리의 `descriptor/m0609_description.yaml`과
`doosan-robot2/urdf/m0609.urdf`는 Isaac Sim의 `LulaKinematicsSolver`가
M0609의 관절 구조와 충돌 구를 읽을 때 사용한다. 결합 로봇의 형상과 물리는 같은
디렉터리 아래의 USD가 담당하므로, Lula 실행에는 URDF가 참조하는 시각화 메시가
필요하지 않다.

- 출처: <https://github.com/mirangy2e/m0609_rg2_urdf>
- 가져온 커밋: `07fbdb35702b38dea7da1ce772abb2288e540982`
- 가져온 날짜: 2026-09-21
- 원본 저장소에는 확인 가능한 라이선스 파일이 없다. 외부 배포 전에는 원 저작자에게
  재배포 조건을 확인해야 한다.
