`full_cycle.sh` 가 `ROS_DOMAIN_ID="${ROS_DOMAIN_ID:-129}"` 라 쉘에 값이 있으면 **그것을 물려받는데**,
이 PC 는 130 이었다. 아래 셋을 맞춰야 붙는다.

    export ROS_DOMAIN_ID=130            # 노드가 실제로 쓰는 값 — /proc/<pid>/environ 로 확인
    export RMW_IMPLEMENTATION=rmw_fastrtps_cpp
    export FASTRTPS_DEFAULT_PROFILES_FILE=$PWD/config/fastdds_local.xml

**부탁**: `return_request.py` 가 구독자 0 일 때 경고 없이 성공처럼 끝난다. 잠깐 기다렸다가
0 이면 비정상 종료하도록 해 주면 이 함정이 사라진다.
