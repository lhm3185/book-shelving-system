# 4. 관절6 여유 ≈0 — 얕게가 아니라 뒤로 빼야 늘었다
분류: 운반 동선 / 삽입
1. 증상: 경로검사 wedge 관절6 한계여유 v07 −0.000, v09 0.012 rad.

6. 고침: `SIM_PICK_Y=-3.049 SIM_GOAL_Y=0.5795`. 짝 규칙 GOAL_Y = 0.5495 + (−3.019 − PICK_Y) (명령좌표 기준).
