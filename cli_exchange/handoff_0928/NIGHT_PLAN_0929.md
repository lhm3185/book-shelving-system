## ① 블록 1 — 네 권 완주 (최우선)

**지금 상태**: 2권 → 3권 → 4권으로 **한 칸씩 전진 중**. 마지막 판(20:48, ROI 0.40)은 2권째에서 중단됨(사람이 PC 정리).

**목표**: 새 텍스처 레벨에서 네 권 4/4 완주 3판.

**최소 산출물 (30~45분)**: ROI 0.40 판을 **한 판 끝까지** 돌려 4권째가 통과하는지 확인하고, 결과를 `cli_exchange/handoff_0928/` 에 한 단락으로 붙인다. 통과하든 실패하든 **로그 줄 원문**을 남긴다.

**확장**: 같은 설정으로 2판 더 → 3/3 이면 태그 `freeze-20260929-shaded` 를 찍는다.

**통과 기준**: `배치 4회 · 완주 1` · 겹침 0건 · 복귀 (+4.986, -5.607) yaw +90.00° · 팔 베이스↔루트 **0.300 m**

**막힘 규칙**: 4권째가 또 서가 책을 물면 **ROI 를 더 내리지 말고**(트레이 칸 3 이 +0.364 라 0.40 이 하한에 가깝다) 아래 순서로:
1. `[Book picked]` 의 `center=(px,py)` 를 본다. py 가 250 근처면 서가, 310~325 면 트레이다
2. 트레이 칸 3 의 실제 팔기준 y 를 `[추적:도착시]` 에서 읽어 ROI 상한과의 여유를 계산해 기록
3. 그래도 막히면 **블록 1 을 여기서 멈추고** 옛 레벨(`freeze-20260928-scan-once`) 회귀 1판으로 기준선만 확인한 뒤 ②로 넘어간다

**절대 하지 말 것**: 문턱을 올려 통과시키기. `tray_match_tol` 은 오늘 0.03→0.05 로 이미 올렸고 근거(M0609 가 같은 이유로 0.06)가 있다. 더 올리지 않는다.

## ② 블록 2 — 교육장 이식 꾸러미

**목표**: 교육장 PC(10.10.0.2)에서 인터넷 없이 도는 꾸러미.

**최소 산출물 (오프라인 — GPU 안 씀)**: `~/b1_demo_bundle/` 에 `demo_env.sh`(작성됨) + `README.txt` + 저장소 태그 목록 + MD5SUMS. 시뮬을 안 띄우고 만들 수 있다.

**확장 (GPU 필요)**: Isaac `File → Collect As` 로 레벨 두 벌(새 레벨·옛 레벨) 수집 → `UsdUtils.ComputeAllDependencies` 로 **못 찾음 0 · 원격 0 · 꾸러미 밖 절대경로 0** 확인 → `du -sh` 로 용량 기록.

**이미 끝난 것**:
- 심볼릭 링크 2개 제거 → 실파일 (`franka_camera.usd` 복사, `env_base_collider.usd` 2,213 B 추출)
- 의존성 검사: 레이어 3 · 에셋 92 · **못 찾음 3**(로봇 원격 3종) · 원격 0 · 꾸러미 밖 0
- 로봇 3종 직접 내려받음 → 하지만 `ridgeback_franka.usd` 가 다시 `Props/panda_*.usd` 13개를 부른다 → **Collect 가 맞다**

**막힘 규칙**: Collect 가 안 되면 원격 3종을 재귀로 내려받는 스크립트를 쓰되, `ComputeAllDependencies` 가 0 이 될 때까지 반복. 그것도 막히면 "인터넷 필요"로 기록하고 ③으로.

**라이선스**: NVIDIA 에셋 — 랩탑이 확인 못 했다. **확인 전까지 공개 저장소 커밋 금지, USB 꾸러미로만.**

## S. 공통 규칙

- 기본 동작 변경 금지 — 새 동작은 환경변수 뒤, 기본값 = 현재 동작
- **문턱을 올려 통과시키지 않는다**
- 한 번에 하나만 바꾼다
- 시간이 아니라 **상태로** 기다린다 (녹화하면 시뮬 시간이 달라진다)
- 판마다 로그를 **즉시 복사**한다 — `shoot1.log` 에 두 판이 섞여 집계를 못 한 전례가 있다
- 판 띄우기 전 `ps aux | grep full_cycle` — 런처 셸이 겹친 적이 있다
- 결과는 실측값으로. 판정 지표: **팔 베이스↔루트 0.300 m**, 배치 4회, 겹침 0건
