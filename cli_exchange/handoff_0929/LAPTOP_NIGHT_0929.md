**먼저 잰다.** 실패한 판의 비전 로그에 도구를 돌린다(시뮬 불필요):

```bash
python3 simulation/isaac/tools/vision_log_report.py <판>/vision.log \
    --slots=-0.188,-0.004,0.180,0.364 --since <4권째 검출 시작 HH:MM:SS>
```

읽는 법:
```
[1] 무리별 통계          "트레이 칸이 아니다" 가 붙은 무리가 끼어든 책이다. 그 무리의 y·z·화면·신뢰도 범위를 본다
    ROI 면까지 최소 여유  트레이 칸3 무리가 y 상한까지 몇 mm 남았는가 — **0.40 으로 내리면 이 값이 20 mm 줄어든다**
[2] 1등의 흐름           끼어든 무리가 몇 프레임 연속으로 이겼는가
[5] 축별 분리 여유       y 말고 더 넓게 갈리는 축이 있는가 (z · 화면 좌표 · 신뢰도)
```

**지금 아는 숫자로 본 y 축의 여유** (9/25 옛 레벨 로그, 새 레벨 값은 위 도구로 다시 잰다):
```

끼어든 검출           (-0.384, 0.477, 0.223)   ← y 0.477, z 는 트레이 책(0.186~0.210)과 9 mm 차이뿐
```

## 2. 새 스위치 — `MAN_BOOK_PREFILTER=true` (기본 false)

```
무엇       책 관측을 **합의 전에** 파지 허용 범위(vision_grasp_region)로 한 점씩 거른다
지금까지   합의(가장 많이 본 무리) → 범위 검사 → 밖이면 **곧바로 410**
켜면       범위 밖 관측은 합의에 못 들어온다 → 범위 안 관측을 끝까지 기다린다 → 없으면 **411**
문턱       그대로. 범위 값은 안 바뀐다. 범위 밖 좌표로는 전에도 안 갔고 지금도 안 간다
왜         410 은 FSM 이 전이하지 못하고 멈추는 코드다(미해결, FSM 담당). 411 은 재시도 가능한 코드다
로그       [책관측] 범위 밖 관측 N개를 합의에서 뺀다 — 마지막 (x, y, z) …
```
**이 스위치가 고치는 것은 "끼어든 책이 범위 밖일 때" 뿐이다.** 끼어든 책이 범위 안(y ≤ 0.42)으로 들어오면
비전 ROI 와 같은 값이라 걸러지지 않는다. ④ 의 해법이 아니라 **410 으로 판이 죽는 것을 막는 안전망**이다.
