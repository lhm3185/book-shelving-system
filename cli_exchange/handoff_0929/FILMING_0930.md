## 오늘 알아낸 것 — **녹화가 느린 원인은 렌더가 아니라 PNG 압축이었다**
```
카메라 3대 붙인 판   서가 도착까지 6분 14초 (녹화 없는 판은 0분 29초) — 12.9배
그때 GPU 사용률       0 %
```
시뮬 루프 안에서 1280×720 PNG 를 동기로 압축하고 있었다. **저장을 큐에 넣고 일꾼 4실이
쓰게** 하고 형식을 jpg(q92)로 바꾸니 **1.4배**가 됐다. 새 스위치:
```
SIM_REC_FORMAT (기본 jpg) · SIM_REC_WORKERS (4) · SIM_REC_QUEUE (256)
SIM_REC_CAMS=auto | 이름=/World/CAM/xxx;…   레벨에 놓인 카메라를 그대로 렌더
SIM_REC_RES=1280x720 · SIM_REC_AUTO=0 (자동 구도 끔) · SIM_REC_DOME=0 (녹화용 돔 라이트 끔)
```

## 카메라 키프레임 — 되긴 하는데 조건이 있다 (`SIM_TIMELINE=1`)
```

render=True                저절로 흐르지만 **실시간 기준**이라 시뮬이 느려지면 카메라만 앞서간다
```
